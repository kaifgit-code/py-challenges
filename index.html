A loop is a way to say "do this again" without writing it again

Imagine printing the numbers 1 to 100. You could write print() a hundred times, or you could write it once inside a loop and let Python repeat it.

The other kind: while

A while loop keeps going as long as its condition is true. You move the counter yourself, so it is easy to forget.

i = 1
while i < 5:
    print(i)
    i += 1      # forget this line and the loop never ends

This prints 1, 2, 3, 4, exactly like range(1, 5).
